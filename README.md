# Esports Team Hub

React + Vite + Tailwind + Supabase team dashboard with Admin, Player and Guest roles.

**Setup: read START-HERE.md** (5 steps, no command line needed).

For the optional edge functions (player account creation, Gmail reminders), see the comments at the top of
`supabase/functions/create-player/index.ts` and `supabase/functions/send-training-reminder/index.ts`.

Run locally: `npm install`, copy `.env.example` to `.env.local`, fill it in, `npm run dev`.
